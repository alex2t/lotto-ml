## Core Data Files

### 1. lotto_draw_history.json (3.6 MB)

**Purpose:** Complete historical record of all lottery draws with rich per-number metadata.

**Structure:** Dictionary keyed by draw date (YYYY-MM-DD format)

**Example:**
```json
{
  "2025-11-05": {
    "draw_index": 407,
    "draw_date": "2025-11-05",
    "winning_numbers": [1, 5, 15, 27, 35, 41],
    "bonus_number": 46,
    "hmc_summary": {
      "hot_count": 3,
      "medium_count": 2,
      "cold_count": 2,
      "hmc_distribution": "3-2-2",
      "draw_range": 40,
      "draw_sum": 124
    },
    "categories_pre_draw": {
      "hot_numbers": [1, 2, 4, 5, ...],
      "medium_numbers": [6, 8, 9, ...],
      "cold_numbers": [3, 7, 11, ...]
    },
    "winning_numbers_details": [
      {
        "number": 1,
        "is_bonus": false,
        "category": "hot",
        "days_since_last_hit": 10,
        "recent_counts": {
          "last_4": 1,
          "last_5": 2,
          "last_9": 3,
          "last_24": 8
        },
        "win_bias_ratio": 1.25,
        "freshness_weights": {
          "freshness_c0_weight": 0.0,
          "freshness_c1_weight": 0.4286,
          "freshness_c2_weight": 0.0
        },
        "current_freshness_bin": 1,
        "is_recent_bonus_hit": true,
        "bonus_hit_contribution": 0.85
      },
      // ... more winning numbers
    ]
  }
}
```

**Key Fields:**

| Field | Type | Description | UI-Friendly? |
|-------|------|-------------|--------------|
| `draw_index` | Integer | Sequential draw number (0-407) | ✅ YES - "Draw #407" |
| `draw_date` | String | Date in YYYY-MM-DD format | ✅ YES |
| `winning_numbers` | Array[6] | Main 6 winning numbers (sorted) | ✅ YES - Display as balls |
| `bonus_number` | Integer | Bonus ball (1-47) | ✅ YES - Highlight differently |
| `hmc_summary.hmc_distribution` | String | Pattern like "3-2-2" (hot-medium-cold) | ✅ YES - "3 Hot, 2 Medium, 2 Cold" |
| `hmc_summary.draw_range` | Integer | max - min | ✅ YES - "Spread: 40" |
| `hmc_summary.draw_sum` | Integer | Sum of 6 main numbers | ✅ YES - "Sum: 124" |
| `categories_pre_draw.*` | Arrays | Number categories before draw | ✅ YES - Show HMC state |
| `winning_numbers_details[]` | Array | Rich metadata per number | ⚠️ MAYBE - Advanced view |

**Use Cases:**
- **UI:** Display draw history with dates and numbers
- **Analysis:** Study historical patterns and trends
- **Validation:** Verify model predictions against actual results

### 2. lotto_trigger_periods.json (55 KB)

**Purpose:** Per-number statistics, HMC categorization, and recent activity patterns.

**Structure:** Dictionary keyed by number (1-47 as strings)

**Example:**
```json
{
  "1": {
    "total_count": 86,
    "last_seen": "2025/11/05",
    "category": "hot",
    "recent": {
      "last_4": 1,
      "last_5": 2,
      "last_9": 2,
      "last_24": 7
    },
    "series": {
      "series": {
        "25_consecutives_8_times": [
          {
            "start_date": "2022/01/01",
            "end_date": "2022/03/26",
            "count": 1
          }
        ],
        "10_consecutives_4_times": [...],
        "6_consecutives_3_times": [...],
        "5_consecutives_2_times": [...]
      }
    }
  },
  "2": {
    "total_count": 79,
    "last_seen": "2025/09/17",
    "category": "hot",
    ...
  }
}
```

**Key Fields:**

| Field | Type | Description | UI-Friendly? |
|-------|------|-------------|--------------|
| `total_count` | Integer | Total appearances | ✅ YES - "Appeared 86 times" |
| `last_seen` | String | Most recent appearance (YYYY/MM/DD) | ✅ YES - "Last seen Nov 5, 2025" |
| `category` | String | "hot", "medium", or "cold" | ✅ YES - Color-code (🔴🟡🔵) |
| `recent.last_4` | Integer | Count in last 5 draws* | ✅ YES - "2 of last 5 draws" |
| `recent.last_5` | Integer | Count in last 6 draws* | ✅ YES |
| `recent.last_9` | Integer | Count in last 10 draws* | ✅ YES |
| `recent.last_24` | Integer | Count in last 25 draws* | ✅ YES |
| `series.*` | Objects | Consecutive appearance patterns | ⚠️ MAYBE - Advanced users |

**Note:** Key naming convention: `last_N` actually counts N+1 draws (historical reason)

**Use Cases:**
- **UI:** Number cards with category, total count, and last seen date
- **Tooltips:** Recent activity ("2 of last 5 draws")
- **Filtering:** Filter by category or recent activity

**HMC Category Distribution (Example):**
- Hot: 15 numbers (most frequent)
- Medium: 17 numbers
- Cold: 15 numbers (least frequent)

### 5. lotto_7_number_freshness_results.json (5.7 KB)

**Purpose:** Freshness pattern analysis - how many "fresh" vs "recycled" numbers appear in draws.

**Freshness Definition:**
- **C0 (Fresh):** Number hasn't appeared in last 4 draws
- **C1 (Seen Once):** Number appeared once in last 4 draws
- **C≥2 (Recycled):** Number appeared 2+ times in last 4 draws

**Example:**
```json
{
  "configuration": {
    "W": 5,
    "C_max": 2,
    "window_description": "Analyze last 4 draws (W-1)"
  },

  "distribution_analysis_7_numbers": [
    {
      "pattern": "C0=3,C1=3,C_GE_2=1",
      "C0_count": 3,
      "C1_count": 3,
      "C_GE_2_count": 1,
      "occurrences": 45,
      "frequency": 0.1103
    },
    {
      "pattern": "C0=4,C1=2,C_GE_2=1",
      "C0_count": 4,
      "C1_count": 2,
      "C_GE_2_count": 1,
      "occurrences": 38,
      "frequency": 0.0931
    }
  ],

  "top_pattern": {
    "pattern": "C0=3,C1=3,C_GE_2=1",
    "frequency": 0.1103,
    "weight_distribution": {
      "C0": 0.4286,
      "C1": 0.4286,
      "C_GE_2": 0.1429
    }
  }
}
```

**Key Fields:**

| Field | Description | UI-Friendly? |
|-------|-------------|--------------|
| `C0_count` | Number of fresh numbers | ✅ YES - "3 fresh numbers" |
| `C1_count` | Numbers seen once | ✅ YES - "3 numbers seen once" |
| `C_GE_2_count` | Recycled numbers | ✅ YES - "1 recycled number" |

**Use Cases:**
- **UI:** "Most common pattern: 3 fresh, 3 seen once, 1 recycled (11%)"


**Key Features (per number):**

| Feature | Range | Description | UI-Friendly? |
|---------|-------|-------------|--------------|
| `appearance_volatility` | 0-2.0 | How erratic the pattern is (CV) | ⚠️ MAYBE - "Pattern stability" |
| `gap_consistency_score` | 0-1.0 | 1/(1+volatility) - consistency | ⚠️ MAYBE - Progress bar |
| `max_gap_ratio` | 1-10 | Max gap / avg gap | ❌ NO - Too technical |
| `appearance_trend` | -1 to 1 | Recent vs older frequency | ✅ YES - "Trending up ↑" or "down ↓" |
| `appearance_acceleration` | -1 to 1 | Very recent vs recent change | ✅ YES - "Accelerating" icon |
| `recent_vs_baseline` | 0-3.0 | Recent vs historical average | ✅ YES - "Currently 25% above baseline" |

**Interpretation Guide:**

**Trend:**
- Positive (>0.2): Number trending up ↑ (appearing more frequently)
- Near zero: Stable →
- Negative (<-0.2): Number trending down ↓ (appearing less)

**Recent vs Baseline:**
- <0.8: Below baseline (currently cold) 🔵
- 0.8-1.2: At baseline (normal) ⚪
- >1.2: Above baseline (currently hot) 🔴

**Use Cases:**
- **UI:** Trend indicators (↑ ↓ →)
- **UI:** "Hot streak" vs "Cold streak" badges
- **Filtering:** Show only numbers trending up

```json

  },

  "overall_distribution": {
    "mean": 144.7,
    "median": 145.0,
    "std": 30.3,
    "min": 75,
    "max": 267
  },

  "anova_analysis": {
    "f_statistic": 175.85,
    "p_value": 0.0000,
    "significant": true,
```
