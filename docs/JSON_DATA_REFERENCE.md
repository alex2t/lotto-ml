## 1. Draw History Data

**File:** `data/lotto_draw_history.json`
**Purpose:** Complete historical record of all lottery draws
**Generated by:** `drawpick.py`

### Structure
```json
{
  "2024-01-15": {
    "draw_index": 305,
    "winning_numbers_details": [
      {"number": 7, "is_bonus": false},
      {"number": 14, "is_bonus": false},
      {"number": 21, "is_bonus": false},
      {"number": 28, "is_bonus": false},
      {"number": 35, "is_bonus": false},
      {"number": 42, "is_bonus": false},
      {"number": 9, "is_bonus": true}
    ],
    "hmc_state": {
      "hot": [7, 14, 21],
      "medium": [28, 35],
      "cold": [42],
      "generic": []
    },
    "freshness_features": {
      "odd_even_pattern_6": "3_3",
      "sum_contribution_score_6": 0.6234,
      "range_spread_affinity_6": 0.7826
    },
    "bonus_hit_analysis": {
      "3": 0.1234,
      "7": 0.2567
    },
    "win_bias_ratios": {
      "1": 1.05,
      "2": 0.95
    }
  }
}
```

### Parameters

| Parameter | Type | Description | User-Friendly? |
|-----------|------|-------------|----------------|
| `draw_index` | Integer | Sequential draw number | ✅ **YES** - Show as "Draw #305" |
| `winning_numbers_details[].number` | Integer | Winning number (1-47) | ✅ **YES** - Display as balls |
| `winning_numbers_details[].is_bonus` | Boolean | Whether number is bonus ball | ✅ **YES** - Highlight bonus visually |
| `hmc_state.hot` | Array | Hot numbers at time of draw | ✅ **YES** - Show as colored indicators |
| `hmc_state.medium` | Array | Medium numbers at time of draw | ✅ **YES** |
| `hmc_state.cold` | Array | Cold numbers at time of draw | ✅ **YES** |
| `freshness_features.*` | Various | Technical freshness metrics | ❌ **NO** - Too technical |
| `bonus_hit_analysis` | Object | Per-number bonus hit scores | ❌ **NO** - Internal ML feature |
| `win_bias_ratios` | Object | Statistical bias ratios | ❌ **NO** - Data scientist level |

### UI Recommendations
- **Display:** Date, draw number, winning numbers (highlight bonus), HMC categories
- **Hide:** All technical features, bias ratios, internal scores

## 2. HMC Data (Hot-Medium-Cold)

**File:** `data/lotto_trigger_periods.json`
**Purpose:** Per-number statistics and categorization
**Generated by:** `drawpick.py`

### Structure
```json
{
  "1": {
    "total_count": 45,
    "days_since_last": 7,
    "category": "hot",
    "recent_4": 2,
    "recent_9": 4,
    "recent_14": 5,
    "series_total": 12,
    "series_recent": 3,
    "bias_ratio": 1.08
  },
  "analysis": {
    "hot_numbers": [1, 7, 14, 21],
    "medium_numbers": [2, 8, 15, 22],
    "cold_numbers": [3, 9, 16, 23]
  }
}
```

### Parameters (Per Number)

| Parameter | Type | Description | User-Friendly? |
|-----------|------|-------------|----------------|
| `total_count` | Integer | Total times number appeared | ✅ **YES** - "Appeared 45 times" |
| `days_since_last` | Integer | Days since last appearance | ✅ **YES** - "Last seen 7 days ago" |
| `category` | String | "hot", "medium", or "cold" | ✅ **YES** - Color-code visually |
| `recent_4` | Integer | Appearances in last 4 draws | ✅ **YES** - "2 of last 4 draws" |
| `recent_9` | Integer | Appearances in last 9 draws | ✅ **YES** |
| `recent_14` | Integer | Appearances in last 14 draws | ✅ **YES** |
| `series_total` | Integer | Total appearance streaks | ⚠️ **MAYBE** - Advanced users only |
| `series_recent` | Integer | Recent streaks | ⚠️ **MAYBE** |
| `bias_ratio` | Float | Statistical bias (1.0 = neutral) | ❌ **NO** - Too technical |

### Analysis Section

| Parameter | Type | Description | User-Friendly? |
|-----------|------|-------------|----------------|
| `hot_numbers` | Array | Current hot numbers | ✅ **YES** - Show as "Hot Numbers" list |
| `medium_numbers` | Array | Current medium numbers | ✅ **YES** |
| `cold_numbers` | Array | Current cold numbers | ✅ **YES** |

### UI Recommendations
- **Display:** Number grid with color-coding (🔴 hot, 🟡 medium, 🔵 cold)
- **Tooltip:** Total count, days since last, recent appearances
- **Advanced View:** Series data for power users
- **Hide:** Bias ratios

- **Boost Multiplier:** "3.5x more likely than random"
- **Hot Picks:** List with confidence percentages
- **Per Number:** "Was bonus 8 times, last 3 days ago"

- Raw occurrence counts

- Series and streak data
