# 🎰 Lotto Analysis Dashboard

A comprehensive Streamlit application for analyzing lottery draw patterns, trigger periods, and historical data.

## 📋 Features

### Trigger Periods Analysis
- HMC (Hot-Medium-Cold) category filtering
- Number-specific filtering
- Series pattern analysis
- Color-coded date display
- Odds calculation
- Pattern detection

### Draw History
- Chronological display (oldest to newest)
- Draw index filtering
- HMC distribution filtering
- Dynamic columns
- Horizontal scrolling tables
- Color-coded categories
- Bonus indicators
