## 🔬 How Values Are Calculated (NOT Estimated!)

### Step 1: Analyzer Reads Real Data

```python
# From lotto_statistics_analysis.json
recent_counts = stats_data['recent_counts']['last_4']

hot_distribution = {
    "4x": 0.65%,   # Hot numbers hit 4 times in last 4 draws
    "3x": 3.53%,   # Hot numbers hit 3 times
    "2x": 18.56%   # Hot numbers hit 2 times
}

# High saturation probability = 3x + 4x
hot_saturation = 3.53% + 0.65% + ... = 22.75%
```

### Step 2: Calculate Across All Windows

```python
# Average across windows (last_4, last_5, last_9)
hot_mean = 25.49%
medium_mean = 20.40%
cold_mean = 14.83%
```

### Step 3: Calculate Relative Risk

```python
# Relative to medium (baseline)
hot_multiplier = 25.49 / 20.40 = 1.291   # 29.1% higher
cold_multiplier = 14.83 / 20.40 = 0.737  # 26.3% lower
```

### Step 4: Generate JSON

Output saved to: `data/lotto_window_saturation_calculated.json`
